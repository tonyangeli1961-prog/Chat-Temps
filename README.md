# Trailer Temperature V3 Production

This package upgrades the prior app to a PostgreSQL-backed production architecture with:
- PostgreSQL persistence
- HTTPS-ready deployment
- Secure bcrypt password hashes
- JWT authentication
- Admin-only controls
- Rate limiting + Helmet
- Browser administrator dashboard
- Excel `.xlsx` server export
- Operator account management
- Fixed temperature standards
- Railway deployment configuration
- Backup worker script and deployment notes

The package is source/deployment code. It does not contain real cloud credentials, signing keys, or an already deployed Railway project.
